# Энергосфера — главная страница

Статический корпоративный сайт ООО «Энергосфера».

## Локальный просмотр
Из этой папки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8765/.

## Содержимое
- dist/index.html — главная, SEO-метаданные и микроразметка организации.
- dist/styles.css — адаптивное оформление.
- dist/script.js — мобильное меню и раскрытие услуги при переходе по якорю.
- dist/assets/logo.jpg — неизменённый оригинал логотипа.
- dist/assets/services.docx — исходный перечень работ.
- dist/assets/photo-credit.html — источник и лицензия настоящей фотографии.

Сайт открыт для индексации. Основной адрес в canonical и sitemap: https://en-sf.ru/.

Вакансии, отдельные страницы услуг, разрешения и выполненные объекты в текущую версию не входят. Главная показывает группы услуг с краткими раскрывающимися описаниями. Фотография тематическая, не объект клиента. Юридический адрес — с. Иглино; исходное SEO-позиционирование — Уфа.
